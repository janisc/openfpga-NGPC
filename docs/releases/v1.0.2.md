# v1.0.2 — saves that survive

**Fixed: a failed restore could destroy your save permanently.** If the core
missed restoring a save on launch, the game concluded it had none and erased
its save block during startup — and the core then wrote that empty result back
over your real save file. One transient failure and the save was gone for
good, with every later launch quietly confirming the loss. A save is now only
written when it actually contains something; an erased image never overwrites
a real one. A missed restore is now something the next launch recovers from.
*(This is the cause of #3 — with apologies to @pomettini, whose file was
already lost by the time we understood it.)*

**Fixed: a fresh cartridge could be given a save that was never delivered.**
The Pocket's staging memory survives a core relaunch, so a previous session's
image could be restored into a copy of a game that had no save of its own. The
core now requires that save data actually arrived before restoring anything.

**New: saves identify their own cartridge.** Every save carries the
cartridge's title and catalogue number, so a save orphaned by renaming or
moving a ROM can always be traced back to its game.

**New: `tools/savinfo.py`.** Decodes any save and reports what is in it —
cartridge, blocks, whether they hold real data or erased flash, and the core's
own counters. **Please include its output when reporting a save problem.**

**Save diagnostics are now enabled in release builds.** Every save file
records how much data arrived, whether any was dropped, and whether the
restore was accepted or rejected. The two bugs above were found and confirmed
with them.

**Work on the save system continues.** A few games touch more flash than the
current save slot can hold and are stored truncated; that, and the remaining
edge cases, are being worked on for the next release.

Thank you to everyone who has filed a bug report or opened a pull request —
every fix in this release came from one.

Saves and savestates from 1.0.0/1.0.1 remain compatible.
Built with Quartus Prime Lite 25.1.
