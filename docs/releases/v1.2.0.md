# v1.2.0 — a link cable to try, on a lighter core

**New and experimental: a link cable between two Pockets.** Two Analogue
Pockets running this core can be joined with an off-the-shelf link cable for
the games' link modes: trading cards, versus matches and the like. **It has
never run on two real Pockets** (we have one), so it may not work at all. If
you try it, please tell us how it went, working or not.

- It is meant for a Game Boy Color link cable or a Game Boy Advance link
  cable, with this core running on both Pockets and nothing else connected.
  Don't connect a real Neo Geo Pocket, a Dreamcast, a MiSTer, a GBA
  wireless adapter or any other device, and leave a GBA cable's middle
  socket empty: nothing else understands what the core sends.
- Take any cartridges out of both Pockets.
- On both Pockets, set **Link Cable** in the core's menu to the cable you use
  (*GBC cable* or *GBA cable*), then start the game. Link Cable is Off at
  every launch.
- Saving or loading a Memory, sleep, or a Reset on either Pocket ends the
  link session.

How it works, and what to try if it doesn't link, is in the
[README](https://github.com/janisc/openfpga-NGPC#link-cable-experimental).

**A lighter core.** The registers of the main CPU and of
the sound CPU now live in the FPGA's small built-in RAM blocks instead of its
logic. That made room for the link cable, and the timing margin is better
than 1.1.1's. The new design was checked against the old one
in simulation and plays as before in our testing, but it changes the heart of
the machine: **if a game behaves differently than in 1.1.1, please report
it.**

**New platform image and an author icon.** The platform image now comes from
Spiritualized1997's openFPGA Platform Art Set, and the core has an author
icon of its own.

Saves and Memories should work in both directions between 1.1.1 and 1.2.0.

## Reporting link cable results

Please open an issue with:

- the cable (make, and whether it is a GBC or a GBA cable; for a GBA cable,
  which Pocket was on the small purple plug);
- the Link Cable setting on each Pocket;
- the game and the link mode you tried;
- which Pocket started the game first;
- what happened: the game found no cable, it connected and then failed, or
  it played.

## Reporting other problems

Please open an issue with the game, what happened just before (sleep, a
Memory, Reset, a relaunch), your Pocket firmware version, and the `.sav`
(and the output of `python3 tools/savinfo.py "<the .sav>"` if you can).

Built with Quartus Prime Lite 25.1.
